[Vingester](https://vingester.app)
==================================

**Ingest Web Contents as Video Streams**

About This Fork
----------------

This is an unofficial fork of [Vingester](https://github.com/rse/vingester) by
[Dr. Ralf S. Engelschall](mailto:rse@engelschall.com), adding a
[Spout](https://spout.zeal.co/) output sink (Windows only) alongside the
existing NDI and FFmpeg sinks, so Vingester's Web content can be sent directly
to Spout-compatible tools such as MadMapper or TouchDesigner. All credit for
Vingester itself goes to the upstream project -- this fork only adds one
feature on top of it. Licensed GPL-3.0-only, same as upstream.

About
-----

**Vingester** (**V**ideo **ingester**) is a small
[Electron](https://www.electronjs.org/)-based desktop application
for use under Windows, macOS or Linux to run multiple
[Chromium](https://www.chromium.org/)-based Web browser instances and
ingesting their rendered Web Contents as screen/window-captured,
[NDI](https://www.ndi.tv/)-multicasted, [FFmpeg](https://ffmpeg.org)-based, or
(in this fork) [Spout](https://spout.zeal.co/)-based (Windows only)
video streams for further use in local or remote video mixing applications or
for local recording.
